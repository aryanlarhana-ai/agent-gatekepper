# 7-Minute Classroom Demo

1. Start the app and show the synthetic-data banner.
2. State the business problem: govern high-risk autonomous order and refund actions.
3. Open the Agent Activity Centre and run the analysis.
4. Trace one missing-ID finding to the order-risk agent, finance risk and executive recommendation.
5. Show conflict resolution in the Executive Decision Report.
6. Download the Excel and PDF reports.
7. Approve or reject one item in the Approval Centre and refresh to confirm SQLite persistence.
8. State assumptions, limitations and that no real transaction is performed.
